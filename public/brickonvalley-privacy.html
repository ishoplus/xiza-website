Brickon Valley Publisher – Privacy Policy

Last updated: 2026-11-16

"Brickon Valley Publisher" (the "API Client") is an internal command-line tool operated by Xiza Co., Ltd. (係咱股份有限公司, Taipei, Taiwan). It uses YouTube API Services solely to manage videos on our own YouTube channel, Brickon Valley (@brickonvalley, channel ID UCBnjDNxFQM--nrLXSwaZYpw). It has no public users and no sign-up.

YouTube API Services

The API Client uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data we access

  • Our own channel's videos, playlists, captions, thumbnails and their metadata (title, description, privacy status, scheduled publish time).
  • Our own channel's analytics reports (views, watch time, audience retention) in aggregate.
  • Public comments posted on our own videos (author display name and comment text), read so we can see feedback on our videos.

How we use, store and share it

  • Data is used only to upload and publish our own videos and to review their performance.
  • The OAuth refresh token is stored in the operator's local macOS Keychain. API responses are printed to the operator's terminal and are not stored in any database.
  • We do not sell, share or disclose any API data to third parties, and do not use it for advertising.
  • No cookies or tracking technologies are placed on any user's device by the API Client.

Revoking access and deletion

Access can be revoked at any time at Google security settings. Any locally cached data is deleted within 30 days of revocation or upon request.
